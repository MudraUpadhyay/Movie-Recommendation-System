# Movie Recommendation System

https://movie-recommendation-system2211.streamlit.app/

Demo video link- https://drive.google.com/file/d/1l68NMEh6p9iS28JDHBBLQEBVuPp_zZ_T/view?usp=sharing

A full-stack movie recommendation application that combines TMDB movie metadata with a TF-IDF similarity model to suggest movies based on content similarity and genre preference.

The project includes:
- A FastAPI backend for serving movie details and recommendation endpoints
- A Streamlit web interface for searching and browsing movies
- Local similarity-based recommendations using precomputed TF-IDF data
- TMDB-powered home feeds, movie details, and genre-based recommendations

## Features

- Search movies by title using TMDB API
- Browse popular, trending, top-rated, upcoming, and now-playing movies
- View detailed movie information including overview, genres, and poster art
- Get AI-style content-based recommendations using TF-IDF similarity
- Discover additional suggestions based on movie genre
- Clean and responsive Streamlit user interface

## How It Works

The recommendation engine uses a hybrid strategy:

1. TMDB API is used to fetch movie metadata, posters, and genre info.
2. A local TF-IDF model analyzes movie descriptions and similarity between titles.
3. Recommendations are generated by comparing the selected movie against the dataset.
4. Genre-based recommendations are produced by discovering other movies within the same category.
5. The frontend displays the results in a user-friendly card-based interface.

## Prerequisites

Before running the project, make sure you have:

- Python 3.10+
- pip
- A TMDB API key

## Installation

1. Clone the repository

```bash
git clone https://github.com/DhananiParita/Movie-Recommendation-System.git
cd Movie-Recommendation-System
```

2. Create and activate a virtual environment

```bash
python -m venv venv
source venv/bin/activate    # Linux/macOS
# venv\Scripts\activate     # Windows
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Configure environment variables

Create a `.env` file in the project root and add your TMDB API key:

```env
TMDB_API_KEY=your_tmdb_api_key_here
```

## Running the Application

### Start the FastAPI backend

```bash
uvicorn main:app --reload
```

The API will be available at:

```text
http://127.0.0.1:8000
```

### Start the Streamlit frontend

Open a new terminal and run:

```bash
streamlit run app.py
```

Then open the local Streamlit URL displayed in the terminal.

## API Endpoints

The backend exposes several endpoints:

- `GET /health` — health check
- `GET /home` — popular/trending movie feed
- `GET /tmdb/search` — search movies in TMDB
- `GET /movie/id/{tmdb_id}` — fetch movie details
- `GET /recommend/genre` — genre-based recommendations
- `GET /recommend/tfidf` — TF-IDF recommendation output
- `GET /movie/search` — combined details + content + genre recommendations

## Recommendations Logic

The application uses a dual recommendation model:

- TF-IDF recommendation: compares similar movie descriptions and metadata to suggest content-related titles
- Genre recommendation: finds movies in the same genre family to expand the recommendations list

This gives users a more relevant and diverse recommendation experience.
